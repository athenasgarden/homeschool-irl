# First 30 days checklist (free)

A launch list from [Homeschool IRL](https://www.teacherspayteachers.com/store/homeschool-irl).

This is not 30 crafts. It is 30 steps so you do not spend September buying boxes and calling that getting ready.

Paid companion: [Your First 30 Days of Homeschooling](https://www.teacherspayteachers.com/Product/Your-First-30-Days-of-Homeschooling-30-Steps-to-Launching-Your-Adventure-11027334).

Check a box only when the thing exists in the real world. Skip anything your state does not require.

## Days 1-7 — legal and small

- [ ] 1. Read your state's homeschool overview. Write the three things they actually require.
- [ ] 2. If notice is required, draft it. Do not decorate it.
- [ ] 3. Pick attendance: notebook dates or [Attendance Tracker](https://www.teacherspayteachers.com/Product/Homeschool-Attendance-Tracker-Printable-Fillable-PDF-Attendance-Log-17598930).
- [ ] 4. Write names and rough grades. That is the school.
- [ ] 5. Choose one default start spot. Not a classroom makeover.
- [ ] 6. Library cards. Libby if you use it.
- [ ] 7. List what you already own. Box what you will not open this month.

If the pile is the problem: [Stop Buying Curriculum](https://www.teacherspayteachers.com/Product/Stop-Buying-Curriculum-Build-Your-Own-Homeschool-17557044).

## Days 8-14 — what school means here

- [ ] 8. Four lines: interests, slipping skill, real-life jobs, Friday definition of done.
- [ ] 9. Daily skeleton on the fridge (start / anchor / 20-minute skill bite / life / close).
- [ ] 10. One math source for 30 days. Not three apps.
- [ ] 11. Read-aloud plus something they pick.
- [ ] 12. How writing happens: notebook, you scribe, or they type.
- [ ] 13. Science this month: kitchen, walk, or one library stack.
- [ ] 14. Tell the child the plan in two minutes.

Framework: [The Simple Homeschool Method](https://www.teacherspayteachers.com/Product/The-Simple-Homeschool-Method-A-Practical-Framework-for-Homeschool-Parents-17556839).

## Days 15-21 — run, then cut

- [ ] 15. One full skeleton day. Write what happened.
- [ ] 16. Cut anything whose setup beat the lesson.
- [ ] 17. One real-life job as curriculum. [Life Skills Are Curriculum](https://www.teacherspayteachers.com/Product/Life-Skills-Are-Curriculum-Real-Life-Learning-Activities-for-Homeschoolers-17557006).
- [ ] 18. One activity covering two subjects. [The One-Activity Homeschool](https://www.teacherspayteachers.com/Product/The-One-Activity-Homeschool-Turn-One-Activity-into-Multiple-Subjects-17556974).
- [ ] 19. If you used a worksheet, ask whether a book, conversation, or job would have done it. [Without Worksheets](https://www.teacherspayteachers.com/Product/Homeschooling-Without-Worksheets-Simple-Alternatives-for-Real-World-Learning-17557063).
- [ ] 20. Attendance for the week, in one sitting.
- [ ] 21. Half-day off if everyone is raw.

## Days 22-30 — survivable

- [ ] 22. If there is a fight pattern, run the [reluctant-learner week](RELUCTANT_WEEK.md) instead of adding work.
- [ ] 23. Weekly admin hour: attendance, library, next week's one anchor.
- [ ] 24. Write what you will not teach this year.
- [ ] 25. One outside human: library, park, grandparent, co-op tour.
- [ ] 26. Portfolio crumb: notebook plus three photos.
- [ ] 27. AI only if it saves time. [AI for Homeschool Parents](https://www.teacherspayteachers.com/Product/AI-for-Homeschool-Parents-Practical-ChatGPT-Strategies-for-Real-Homeschooling-17557024).
- [ ] 28. Optional 10-minute language. [Lifeprint](https://www.lifeprint.com/) or [Beginner ASL](https://www.teacherspayteachers.com/Product/Beginner-ASL-Activities-30-Days-of-American-Sign-Language-for-Homeschool-17599700).
- [ ] 29. If you are about to buy a full-year kit to soothe anxiety, stop.
- [ ] 30. Write next month's four lines. Keep the skeleton. Change only the anchor.
