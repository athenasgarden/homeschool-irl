# Homeschool IRL — free guides

Useful homeschool pages you can run with a library card, a kitchen, and a timer. Paid printables stay on Teachers Pay Teachers.

**Store:** [teacherspayteachers.com/store/homeschool-irl](https://www.teacherspayteachers.com/store/homeschool-irl)

This repo is a catalog + free guides. Do not upload TPT product files here.

## Guides

| Page | For |
|---|---|
| [ONE_WEEK.md](ONE_WEEK.md) | One week without buying more curriculum |
| [RELUCTANT_WEEK.md](RELUCTANT_WEEK.md) | Reset week when every day is a fight |
| [FIRST_30.md](FIRST_30.md) | 30 launch steps, checkbox form |
| [CATALOG.md](CATALOG.md) | Exact TPT product URLs for Pins and this site |

HTML versions (`index.html`, `reluctant.html`, `first30.html`) live in the same folder if you turn on GitHub Pages.

## How to use

1. Send a parent the guide that matches their pain.
2. They run the week from a notebook. No account required.
3. Product links in each guide go to the exact TPT URL.
